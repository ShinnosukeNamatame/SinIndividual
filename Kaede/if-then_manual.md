# 怒られた事象の全列挙 と if-then マニュアル

---

## 原則

怒る構造は「X(行為)→Y(その行為が意味すること)→Yが許せない」である．
個別ルールはXを減らすためのものだが、Xを減らしても「Yを分かっていない」と伝われば無効になる．

**共通ルール**

- IF 指摘を受けた・謝る → THEN 「分かった」「ごめん」単独で終えず、①何をしたか ②それが楓さんにどう見えたか ③いつまでに何をするか
  を自分の言葉で言う．
- IF 何かを宣言する → THEN 日時・場所・完了条件まで決めて、その場でカレンダー登録．宣言と実行の乖離が最大の不信源
- IF 自分の状態(眠い・だるい・分からない)を伝える → THEN 黙って消えるのではなく、状態を言葉で申告してから離れる．

---

## A. 連絡・返信

### A1. 放置

- IF 返す内容が決まらない → THEN 「考えてる、◯時までに返す」
- IF 忙しくてすぐ返せない → THEN「忙しいから後で返す」
- IF 深夜で眠い → THEN 「寝る、朝◯時に返す」
- IF 重い話の最中 → THEN 生活動作で抜けない．抜ける必要があるなら「◯分で戻る」と言い、必ず戻る．
- IF 本当に限界 → THEN 「今夜はここまでにしたい、明日◯時に続ける」と宣言してから終える．無言で切らない．

### A2. 途中報告がない

- IF 予定や行動が変わる → THEN 変わった時点で送る．着いてから、終わってから、ではない．
- IF 楓さんに関わる用事を進めている → THEN 進捗を「今◯まで終わった」と区切りごとに送る．

### A3. 夜遅く長話

- IF 23時以降 → THEN 重い話題を始めない．翌日の昼に「今日◯時に話したい」と予約する．
- IF 眠くて機嫌が悪くなりそう → THEN D4の通り申告して切り上げる．

### A4. 話題

- IF 1日連絡していない → THEN 自分から、楓さんの今日について聞く
    - 「今日どうだった」ではなく、彼女の予定を把握した上で「◯◯どうだった？」

## B. 約束・予定・時間

### B1. 遅刻

- IF 待ち合わせがある → THEN 前日にアラーム+出発時刻を逆算して登録．到着予定より15分前に着く設定．
- IF 遅れる → THEN 分かった時点で連絡
    - 指摘されたら不機嫌にならない．
    - 状況報告

### B2. 予定を立てない・流す・リマインドされるまで動かない

- IF 「◯◯しよう」と話が出た・楓さんにリマインドされた → THEN その場で日付候補を3つ出し、決まったらカレンダーに入れ、必要な予約・調べ物の担当と期限を自分から言う．

### B3. 予定変更

- IF 自分の都合で予定を変えたい → THEN 変更は相手の時間を奪う行為だと認識し、理由+謝罪+代替案をセットで出す．
- IF バイト・学校の予定 → THEN 決めたら変えない

### B4. 言われたことを忘れ同じ指摘を繰り返される

- IF 指摘・要望・約束を受けた → THEN 会話中にメモアプリへ書く
    - 週1金夜で見返す時間をカレンダーに固定．
- IF 同じ指摘を2回目に受けた → THEN 「前にも言われた」と自分から認め、2回目が起きた原因と対策を言う．

### B5. 楓さんの予定を見ていない

- IF 聞きたい → THEN 先に楓さんの予定を確認してから出す．共有カレンダーがあるなら毎朝見る．

### B6. 予定を立てる

- IF １日の終わり → 次回予定の日程と場所を決める
    - 帰る必要があるなら会う前に伝える．

## C. お金

### C1. 貯金しない

- IF 収入があった → THEN 受け取った日に定額を別口座へ移す(自動振替)

### C2. お金の話・「お金がない」を会話に持ち込む

- IF 楽しい予定の話をしている → THEN 費用の話をその場で出さない
    - 必要なら別の時間に「予算は◯円で考えてる」と自分の案として出す．

### C3. 高額な買い物をする

- IF 3万円以上の買い物 → THEN 買う前に相談する．
    - 貯金より優先する理由が言えないなら買わない．

### C5. 同棲・家賃の予算や頻度を申告しない

- IF 住まい・費用の話 → THEN 自分が出せる額・来られる頻度を、先に数字で出す．
    - 提案を「無理」で返さない．

### C6. 振込の意味や金銭のやり取りを把握していない

- IF お金を受け取った/払った → THEN その日に「何のお金か・いくら・誰から誰へ」をメモに記録する．

### C7. お礼が楓さん経由になる

- IF 楓さんの家族に世話になった → THEN 自分の口で、その日のうちに直接お礼を言う．

## D. 会話・態度

### D1. 「分かった」「はいー」「うん」

- IF 何かを話した, 指摘した → THEN 内容を自分の言葉で言い換えて返す+自分の考えを1つ足す．

### D2. 相手のことを聞かない・話が終わるのを待つ

- IF 会話中 → THEN 話に質問を1つ返す(「それでどうなったの？」「どう思った？」)．
    - 自分の話は、相手の話への質問を2つ以上して深掘りした後

### D3. 質問に質問で返す・質問攻めにする・自分で考えない

- IF 分からないことがある → THEN まず自分で調べる/考えて、自分の仮の答えを添えてから聞く．
    - 「どういう意味？」単独で返さない．
- IF 質問された → THEN 質問に答える．答えてから、必要なら聞き返す．

### D4. 不機嫌を態度に出す・機嫌で返答が変わる

- IF 眠い・空腹・疲れで機嫌が悪い → THEN 「今疲れてて返答が雑になりそう．◯時に話す」と申告して切り上げる．
    - 不機嫌な短文で返さない．
- IF 楓さんが怒っている → THEN 反射で怒り返さない．
    - じっくり文章を読んで主張を理解する

### D5. 指摘を受けた時

- IF 指摘された → THEN 最初の返答に反論・補足・「でも」を入れない．
    - まず「どの行為が、どう見えたか」を復唱．
    - 反論は翌日以降、別の時間に．

### D6. 遠回しな言い方

- IF 提案・返答をする → THEN 選択肢ではなく自分の案を1つ出す．「どっちでもいい」「楓さんはどうしたい？」で返さない．

### D7. 論点が違うと気づいても切り替えない

- IF 自分の説明が的を外していると感じた → THEN 説明をやめ、「論点がずれてた．楓さんが言ってるのは◯◯だよね」と切り替える．

### D8. 楓さんを話し相手扱いする・都合よく会話する

- IF 楓さんに話しかける → THEN 自分の悩み・解説・情報ではなく、状態への関心から始める．自分の話は彼女の話の後．

### D9. 過去の話への反応が冷たい/拒絶

- IF 過去の出来事や性被害に関わるニュースを出した → THEN 評価・分析・自分の側の反応(男全体が否定された等)を言わない．
    - 「それは怖かったよね」と体験への共感
- IF 容量的に受け止められない → THEN 「今は受け止めきれないから、◯時にちゃんと聞きたい」と申告．
    - 無視や適当な返事「へー」最悪．

### D10. 説明で相手の訴えを無効化する

- IF 自分の行為の理由を説明したくなった → THEN 先に「楓さんに何が起きたか」を言う
    - 理由は聞かれるまで言わない．
    - 言うときも「だから仕方なかった」に接続しない

**電話中に離脱する場合の報連相(必ずこの順番)**

1. 報: 「今から◯◯する(トイレ/水を飲む/充電/宅配)」— 何をするかを先に言う
2. 連: 「◯分で戻る」— 戻る時刻を言う．「ちょっと待って」は禁止
3. 相: 「切らずに置いといていい？」または「一回切って◯分後に掛け直していい？」— 切るかどうかを相手に確認する
4. 戻ったら第一声で「戻った、続けて」— 戻ったことを言う

- IF 時間内に戻れない → THEN 延長を先に送る(「あと5分かかる」)．
- IF 楓さんが「行かないで」と言った → THEN 生理的に不可能でない限り行かない．その場でやる必要がないこと(
  シャワー・洗い物・食事)は、話の後に回す．

### D11b. 会話中・テキスト中に黙ってしまう

黙る原因は主に3つ．原因ごとに出す言葉が違う．

**原因① 何を言えばいいか分からない(思考が止まる)**

- IF 返答が出てこない → THEN 3秒以内に「今、言葉が出てこない」と言う．黙るより先に、黙っていることを言葉にする．
- IF 考える時間が要る → THEN 「◯分ください、それまでに必ず言う」と時間を切る．
- IF 時間内に出なかった → THEN 出なかったことを言い、途中でもいいから今ある分を出す
    - 「まだまとまってないけど、今あるのは◯◯」
- テキストの場合: 「見た．考えてる．◯時までに返す」を先に送る．既読だけで止めない．

**原因② 言うと怒られそうで言えない(保身で止まる)**

- IF 言いたいことがあるが怒られそう → THEN 「言うと怒られそうで止まってる．でも言う」と前置きして言う．
    - 前置きが無い沈黙は、「隠している」に見える
- IF 自分の考えは違う → THEN 違うことを言う．
    - 黙って同意する方が、後で「本当は違った」が出て信頼を失う

**原因③ 相手の言葉で固まった(ショック・処理落ち)**

- IF 強い言葉を受けて頭が真っ白 → THEN 「今、頭が真っ白になった．聞いてる．少し待って」と言う．
- IF 第三者の前で固まった → THEN E1の通り、一言でいいので彼女の側に立つ．
- IF 固まったまま時間が過ぎた → THEN 後から「あのとき固まって何も言えなかった」と自分から言う．

**共通: 黙る前に必ず出す一言(暗記する)**

- 「今、言葉が出てこない」
- 「◯分ください」
- 「怒られそうで止まってる、でも言う」
- 「頭が真っ白になった、聞いてる」

### D12. 自分の話・自分の反省にすり替える

- IF 反省や今後を語る → THEN 主語を二人の関係にする．
    - 「俺は〜」で始まる文が続いたら止めて、「楓さんにとって〜」に書き直す．

### D13. 開き直る・発達障害/経験不足を理由にする

- IF 失敗の理由を聞かれた → THEN 「発達障害だから」「経験がないから」を理由に置かない．
    - 事実として何をしなかったかだけ言う．

### D14. 疑問

- IF 質問 `?` $\rightarrow$ THEN 質問に答える

## E. 思いやり・想像力・立場

- IF 第三者が楓さんを批判・叱責した → THEN その場で一言、彼女の側に立つ発言をする
    - 完璧な反論は要らない．
        - 言えなければ、楓さんの隣に立つ・彼女の側を向く、という体の位置だけでも変える．
        - 同調・沈黙・笑いは加担になる．
- IF 公共の場 → THEN 下げる話題を一切しない．
- IF 公共の場で自分の話をする → THEN 楓さんの近況・仕事・良いところを、自分から1つ入れる．

### E3. 気遣い・機嫌取りが一方通行

- IF 楓さんが自分のために何かした(親への配慮・買い物・段取り) → THEN 具体的に言葉で返す+同種のことを自分からやる．
- IF 楓さんが不機嫌 → THEN 大人しくするのではなく、「何があった？」と聞く．

### E5. 会うときに計画・準備がない

- IF 自分から誘った → THEN 店・時間・移動を自分が調べ、当日は自分が店員と話す．

### E6. 心配しない・気づかない(体調・変化・悲しみ)

- IF 楓さんが移動する・体調が悪い・検査がある → THEN 前後に一言(「着いた？」「どうだった？」)．カレンダーに予定も入れる．
- IF 楓さんの反応が普段と違う(短い・遅い・wwww) → THEN それは怒りか悲しみの信号．「何かあった？」と聞く．

### E7. 立場を分かっていない(頼っている側だという認識)

- IF 楓さんや楓さんの家族の資源(家・お金・時間)を使っている → THEN それを当然と扱わない．使った分を言葉と行動で返す．

### E8. 楓さんの母・家族へのリスペクトがない

- IF 楓さんの家族の話 → THEN 批判・分析をしない．お世話になったら直接お礼(C7)．

### E9. 「楓さんがどう感じたか」を推し量る動機が自分の保身

- IF 楓さんの気持ちを考える → THEN 「怒られないために」ではなく「彼女に何が起きているか」を問う．答えが自分の話になったらやり直す．

## F. 生活・自己管理

### F1. ゲーム・スマホ

- IF 楓さんといる/連絡中 → THEN ゲームをしない．会話中にスマホの別画面を見ない．

### F2. 服・身だしなみ

- IF 会う日 → THEN TPOに合う服を前日に決める．季節ごとに最低限のパターンを持つ．

### F3. 睡眠・体力

- IF 深夜に議論が続く → THEN 翌日の予定を守れる時刻で切る(D11)．睡眠不足での返信は誤読を生む．

### F4. 記憶が曖昧・記憶を都合よく書き換える

- IF 過去の事実について話す → THEN 記憶ではなくLINE・メモ・カレンダーを見てから答える．
